    Peak Performance

    Veii is written in the Rust programming language, which allows for, among other things, very good performance, optimizations, and low memory usage. Veii uses this to the fullest, and has the goal to minimize resource usage and maximize performance.

    ECS Architecture

    Unlike most UI frameworks and libraries, Veii internally uses the "Entity Component System" (ECS) paradigm, and we have applied many features of it for our end-user API. For UI, this is a very stupid idea, but I've done it anyway!

    Safety

    Rust uses its inbuilt borrow- and type-checker to guarantee many restrictions at compile-time. This avoids many bugs and safety risks before they could possibly manifest at runtime.

    Multi-Platform

    Veii can run on a variety of platforms. We utilize our modular app and backend system to allow for easy multi-platform support. Veii can even run on the web, using WebAssembly
