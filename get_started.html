    Getting Started

    • Check out our

      • GitHub
      • crates.io page

    • Use the crate

      Add as dependency:

      To create your own custom applications in Rust with Veii, use cargo add veii to add Veii as a depedency to your own project. Allows you to create your own custom UI node properties, compile you own runtime, or write your application in pure Rust.

      Install runtime version:

      There is also a precompiled runtime version of Veii, which can read create UIs from script- and custom-format markup-files. Currently, it is also installed though Cargo, by running cargo add veii-runtime in your command line.
